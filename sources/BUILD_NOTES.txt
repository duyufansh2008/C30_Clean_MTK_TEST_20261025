Historical build environment: Windows x64, JDK 8, Android SDK platform 30 r03 and build-tools 30.0.3, Cygwin e2fsprogs 1.44.5. Historical APK and validation snapshots remain in the repository; they do not automatically include later source changes.
Current launcher build instructions, exact firmware workspace inputs, regression tests and release packaging are documented in docs/BUILD_AND_RELEASE.md. The launcher builds from sources/launcher/ on Windows or Linux using the supplied SDK/JDK paths, without the original Codex working directory. Firmware reconstruction requires the user's corresponding original backup and local workspace inputs; super images are local inputs and must not be committed or uploaded.
The checked-in signing key is public development material, not a private release key. See docs/BUILD_AND_RELEASE.md.
